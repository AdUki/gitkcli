# Return from a blame/origin jump via the jump list ([<-] / Ctrl-Left).
# Open a3d1fd1's diff, blame the removed "version" line (Enter) which jumps to the
# origin commit abc7af0, then step back with Ctrl-Left. The blame records exactly
# one point - the line it was fired from - so a single step lands back on
# a3d1fd1's diff at that line ([16/24]), in the diff pane.
size      120x40
config    default
run       git checkout --detach a3d1fd1
launch
key       <Enter>
wait      stable
key       j*15
key       <Enter>
wait      stable
key       <C-Left>
wait      stable
capture   back
