# Jump-to-file navigation inside a diff. ef36129 touches two files; open its diff
# and press Enter on the second per-file stat line ("tests/test_smoke.py"). The
# cursor jumps to that file's "diff --git .../test_smoke.py" hunk (item 20) and,
# on this short screen, the viewport scrolls down to reveal the test_smoke.py
# hunk. A short pty makes the scroll visible (not just a title-counter change).
# The jump records exactly one point, so a single Ctrl-Left restores the stat
# line and the scroll position it was fired from.
size      120x16
config    default
run       git checkout --detach ef36129
launch
key       <Enter>
wait      stable
key       j*7
wait      stable
capture   at_stat_line
key       <Enter>
wait      stable
capture   jumped
key       C-Left
wait      stable
capture   back_to_stat_line
