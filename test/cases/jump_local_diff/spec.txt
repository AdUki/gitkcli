# A jump point on an uncommitted (local-*) diff. Detached HEAD + dirty README
# gives a working-dir pseudo-row; g jumps to it and Enter opens its diff, then G
# inside that diff records a point on it. Open a commit's diff instead, then walk
# back: one step to that commit's log row, a second onto the local point, which
# reloads the uncommitted diff (show_worktree) and raises the diff pane again.
size      120x40
config    default
run       git checkout --detach master && printf 'junk\n' >> README.md
launch
wait      stable
key       g
key       <Enter>
wait      stable
key       G
wait      stable
key       q
key       <Down>*3
key       <Enter>
wait      stable
key       C-Left
wait      stable
key       C-Left
wait      stable
capture   back_to_local
